Create an array called -games- containing:
    -----------------
    |     Pong      |
    |     Chess     |
    |     Tetris    |
    |     Pacman    |
    -----------------

Then:
1. Print the first game.
2. Print the last game.
3. Print the length.
4. Add "Street Fighter" to the end.
5. Remove the last game.
6. Change "Chess" to "Tennis".
7. Print the whole array.

You should end up with:
    ["Pong", "Tennis", "Tetris", "Pacman"]

Part 2 — array + objects
Now create:

    const players = [
        // YOUR OBJECTS HERE
    ];

Create three player objects.
Each player must have:
    -----------------
    |    username   |
    |    age        |
    |    score      |
    |    online     |
    -----------------

For example, conceptually:
        players
         ├── Houda
         ├── Ali
         └── Sara
Give them whatever values you want.

Then:

1. Print Houda's username.
You should use the idea:
    players[0].???

2. Print Ali's score.
    players[1].???

3. Change Sara's score to 2500.

4. Change Ali's online status to false.

5. Add a fourth player using:
    players.push(...)

6. Print how many players you have.

7. ⭐

Use a for loop to print:
      Houda   -  2000
      Ali     -  1500
      Sara    -  2500
      Youssef -  1700

The important part is that you should access the properties dynamically:
        players[i].username
        players[i].score

rather than manually writing:
    players[0].username
    players[1].username
    players[2].username

Part 3 — the important challenge 🧠

Create:
    const tournaments = [
        ...
    ];

Each tournament should be an object containing:
    --------------
    |   name     |
    |   game     |
    |   players  |
    --------------
And players itself should be an array of objects.

So your structure should look like:
        
        tournaments
         │
         ├── [0] → tournament object
         │           ├── name
         │           ├── game
         │           └── players
         │                 │
         │                 ├── [0] → player object
         │                 ├── [1] → player object
         │                 └── [2] → player object
         │
         └── [1] → tournament object
                     ├── name
                     ├── game
                     └── players

Then try to print:
    -- The first player's name in the first tournament --

You'll need something like:
    -- tournaments[0].players[0].username --

Don't memorize that line. Understand the path:
        
        tournaments
            ↓
        [0]              ← first tournament
            ↓
        .players         ← its players array
            ↓
        [0]              ← first player
            ↓
        .username        ← player's name

Part 1 — Basic function
Create:

    function multiply(a, b) {
        // ...
    }

It must return the multiplication of a and b.

Then:

    const result = multiply(5, 4);
    console.log(result);

Expected:
20

Part 5 — ⭐⭐ Find a player

Create:

    function findPlayer(players, username) {
        // ...
    }

It should search the array and return the matching player.

For example:
    const player = findPlayer(players, "Sara");
    console.log(player);

Expected:
    {
        username: "Sara",
        score: 1800,
        online: true
    }

Then:
    console.log(player.score);

should give:
    1800

If the player doesn't exist:
    const player = findPlayer(players, "Youssef");
    console.log(player);

return:
    null

The structure you're practicing

By the end, you'll have:

                    FUNCTIONS
                        │
              ┌─────────┼─────────┐
              │         │         │
          parameters   return   calls
              │
              ▼
          ┌───────────────┐
          │               │
        ARRAYS          OBJECTS
          │               │
          └───────┬───────┘
                  │
                  ▼
            REAL PROGRAM

And the most important pattern to understand is this:

        function printPlayers(players) {
            for (let i = 0; i < players.length; i++) {
                console.log(players[i].username);
            }
        }

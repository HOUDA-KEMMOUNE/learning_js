    1

Exercise 5 — Player list

Now let's combine your objects + arrays + DOM + callbacks.

Given:
    const players = [
        {
            username: "Houda",
            score: 2000,
            online: true
        },
        {
            username: "Ali",
            score: 1500,
            online: false
        },
        {
            username: "Sara",
            score: 1800,
            online: true
        }
    ];

HTML:
    <h1>Players</h1>
    <div id="players"></div>

Your job:

Step 1
Select:
    <div id="players">


Step 2
    Use .forEach() or .map() to go through the players.

Step 3
For every player, create:
    <p>Houda - 2000</p>
    <p>Ali - 1500</p>
    <p>Sara - 1800</p>

and add them to the page.

Exercise 6 — 🔥 Your first mini-project

Build a tiny player dashboard.

HTML should have:
    -> Player name input
    -> Score input
    -> [ Add Player ]

    Players:
    ----------------
    Houda - 2000
    Ali - 1500
    Sara - 1800

When the user enters:
    Username: Youssef
    Score: 2200

and clicks:
    Add Player

the page should become:
    Houda - 2000
    Ali - 1500
    Sara - 1800
    Youssef - 2200

Store the players in:
    const players = [];

Then when the button is clicked:
    read input
       ↓
    create object
       ↓
    push object into players
       ↓
    update DOM

This one exercise combines objects + arrays + functions + callbacks + events + DOM.

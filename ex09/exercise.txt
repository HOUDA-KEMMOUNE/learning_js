Part 4 — Add a bonus

Create another .then() that adds 500 points.

Don't modify the original object.

Use spread:
    {
        ...player,
        score: player.score + 500
    }

So:
    Houda
    2000
       ↓
    +500
       ↓
    2500

Part 6 — Final challenge

Create:
    const processPlayer = (username, callback) => {

    };

It should:
    -> Get the player asynchronously.
    -> Add 500 points.
    -> Pass the resulting player to callback.
    -> Return the result.
    -> Handle errors.

Then create:

    };

And:

⚠️ One rule for this exercise

Don't use async/await yet.

I want you to first become comfortable with:
    -> new Promise()
    -> resolve()
    -> reject()
    -> .then()
    -> .catch()
    -> .finally()

and especially:
    Promise
       ↓
    .then()
       ↓
    .then()
       ↓
    .then()
       ↓
    .catch()

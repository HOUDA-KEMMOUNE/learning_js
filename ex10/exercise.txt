Part 1 — getPlayer()

You already know how to do this.

Create:
    getPlayer(username)

It must:

    -> Return a Promise.
    -> Wait 1 second using setTimeout.
    -> Search the array with .find().
    -> If the player exists → resolve(player).
    -> Otherwise → reject(new Error("Player not found")).

So conceptually:
    getPlayer("Houda")
           ↓
        1 second
           ↓
        players.find()
           ↓
       ┌────┴────┐
     exists     doesn't
       ↓           ↓
    resolve      reject

Part 4 — Create getOnlinePlayers()

Now combine your Promise knowledge with arrays.

Create an async function:
    getOnlinePlayers()

It should:
    -> Wait for some asynchronous operation that returns the players array.
    -> Use .filter().
    -> Keep only online players.
    -> Return the resulting array.

Then print their usernames using .map().

So the flow is:
    await getPlayers()
           ↓
        players
           ↓
       .filter()
           ↓
    online players
           ↓
        .map()
           ↓
    usernames

This combines:
    -> Promise
    -> async
    -> await
    -> arrays
    -> objects
    -> filter
    -> map
    -> arrow functions
    -> destructuring

⚠️ One important restriction

For the main solution:

Don't use .then() / .catch() for the asynchronous flow.

Use:
    -> async
    -> await
    -> try
    -> catch

But you are still absolutely allowed to use:
    -> map()
    -> filter()
    -> find()

because those are array methods, not Promise handling.

Your cheat sheet

Keep this next to you while doing the exercise:

    PROMISE
    ─────────────────────────────
    
    new Promise((resolve, reject) => {
        ...
    })
    
    resolve(value) → success
    reject(error)  → failure
    
    
    PROMISE STYLE
    ─────────────────────────────
    
    promise
        .then(result => ...)
        .catch(error => ...)
    
    
    ASYNC/AWAIT
    ─────────────────────────────
    
    async function test() {
    
        try {
        
            const result = await promise;
    
        }
        catch (error) {
        
            console.log(error.message);
    
        }
    }
    
    
    IMPORTANT
    ─────────────────────────────
    
    async function
           ↓
    always returns a Promise
    
    await promise
           ↓
    get the fulfilled value
    
    rejected Promise
           ↓
    await
           ↓
    caught by try/catch
    
    
    DATA
    ─────────────────────────────
    
    object       → { ... }
    array        → [ ... ]
    
    destructuring
    const { username, score } = player;
    
    array destructuring
    const [first, second] = players;
    
    
    SPREAD
    ─────────────────────────────
    
    const copy = { ...player };
    
    const updated = {
        ...player,
        score: player.score + 500
    };
    
    
    ARRAY METHODS
    ─────────────────────────────
    
    map()    → transform every element
    filter() → keep elements that satisfy condition
    find()   → find one element
    forEach() → execute something for every element
    
    
    FUNCTIONS
    ─────────────────────────────
    
    function add(a, b) {
        return a + b;
    }
    
    const add = (a, b) => a + b;
    
    
    CALLBACK
    ─────────────────────────────
    
    function receives another function
    
    map(player => ...)
    filter(player => ...)
    
    
    ERRORS
    ─────────────────────────────
    
    throw new Error("message");
    
    try {
        ...
    }
    catch (error) {
        console.log(error.message);
    }

🔥🔥 Part 9 — Spread + map + destructuring

This one is closer to what you'll eventually do in React.

Create a function:
    const addBonus = ...

It receives the players array and returns a NEW array where every player gets 500 additional points.

For example:
    Houda: 2000 → 2500
    Ali:   1500 → 2000
    Sara:  1800 → 2300

Requirements:
    -> Don't modify the original players
    -> use .map()
    -> use destructuring
    -> use object spread
    -> use an arrow function


The conceptual structure should be:
    players
       ↓
    map()
       ↓
    take one player
       ↓
    destructure username / score / ...
       ↓
    create NEW object with ...player
       ↓
    replace score
       ↓
    new array


This last exercise is really worth understanding, because the combination of:
    map()
    +
    destructuring
    +
    spread
    +
    arrow functions
    +
    objects
    +
    arrays

is basically the vocabulary you'll start seeing everywhere once you move into React.
